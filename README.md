

# 🤖 Anees GPT

**Anees GPT** is a full-stack, AI-powered conversational web application inspired by ChatGPT. It enables users to interact with an intelligent assistant in real time, leveraging modern frontend technologies, a scalable backend, and a powerful Large Language Model (LLM).

This project demonstrates how to build a **production-style AI product** using real-world tools and APIs.

---

## 🚀 Project Highlights

* Real-time AI chat experience
* Powered by **Gemini 2.0 Flash (LLM API)**
* Full-stack architecture (Frontend + Backend)
* Clean, responsive, and modern UI
* Scalable and modular codebase

---

## ✨ Key Features

* AI-driven conversational interface
* Real-time message processing
* Secure API-based response generation
* Chat history stored in database
* Error handling and validation
* Production-style REST API

---

## 🛠️ Tech Stack

### Frontend

* **React.js** – Modern component-based UI
* **JavaScript (ES6+)** – Client-side logic
* **CSS3** – Responsive and clean styling

### Backend

* **Node.js** – Server runtime
* **Express.js** – RESTful API framework
* **MongoDB** – NoSQL database for chat data
* **MongoDB API (JavaScript SDK)** – Database integration
* **Gemini 2.0 Flash API** – Large Language Model (LLM)
